# Softglow Threshold

**A quiet fantasy romance novel (romantasy).**  
Book One of the Softglow sequence. Written by R. Snodgrass III.

---

## What this is (plain English)

Softglow Threshold is a slow-burn fantasy romance about:

- **Lina Reed** — a woman carrying a loss that is starting to fade from her own mind  
- **The Softglow** — a strange living place (an archive) that holds leftover human memories as soft golden and rose-colored threads of light  
- **The Archivist** — a precise, careful man bound to that place  

Lina walks through a doorway that should not open and ends up inside the Softglow. The magic is soft: attention, residual heat, and memory that can thin or stay coherent. There are no dragon wars or fae courts. The tension is intimacy, presence, and whether connection can survive pressure.

**Genre:** Quiet liminal romantasy / atmospheric fantasy romance  
**Tone:** Sensory, slow, emotional, deliberate  
**Series:** Book 1 of Softglow (later books teased as additional “thresholds”)

## This repo

This is the marketing / landing page for the book.

- Interactive doorway hero with residual light threads  
- Sections that explain the world, characters, and series  
- CTA toward reading the book (Amazon / retailers)

### Run locally

```bash
npm install
npm run dev
```

### Build (static export)

```bash
npm run build
```

Output goes to `out/` — deploy that folder to Vercel, Netlify, GitHub Pages, or any static host.

### Deploy on Vercel

1. Import this repo at [vercel.com/new](https://vercel.com/new)  
2. Framework: Next.js  
3. Deploy  

Live URL will be something like `https://softglow-threshold.vercel.app`

## Design notes

Colors: void black, paper-gold, soft rose.  
Motion: slow, residual, never frantic.  
The site is meant to feel like approaching a threshold — but the story and pitch should still be understandable in the first few seconds.
